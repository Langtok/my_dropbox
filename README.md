# Welcome to My Dropbox
***

## Task
The problem is implementing a serverless file synchronization system like Dropbox, allowing users to upload, store, and synchronize files securely. The challenge is integrating AWS services like Amplify, Lambda, and S3 to handle authentication, storage, file upload, versioning, and cloud hosting, all while scaling automatically.

## Description
To solve this, I've utilized AWS Amplify for quick backend setup and user authentication, AWS Lambda for backend logic, and S3 for scalable file storage. The ReactJS frontend communicates with these services to allow file uploads, manage versions, and authenticate users.

## Installation
To get started with the project, follow these steps:

Clone the repository:
$> git clone <repository_url>
$> cd my_dropbox

Install the dependencies:
$> npm install

Set up AWS Amplify with your project:
$> amplify init
$> amplify add auth
$> amplify add storage
$> amplify push

## Usage
To use this project, follow these steps:

Run the React app:
$> npm start

Users can log in, upload files, and sync files across devices. The project uses a serverless backend that scales with usage.
